# BattUse Log Viewer

In its current state, in the absence of a sufficient number of tests, live use of the widget is not recommended.

**Minimum required EdgeTx version:** 2.11.5 (recommended: 2.12.5, Latest )  
This widget uses LVGL for its graphical interface.  
Tested during development on a Radiomaster TX16S radio.

This script is linked to the BattUse Widget, it cannot be used by itself.
Requires BattUse Widget installed to work.

Please read the [Wiki page](https://github.com/Be-Gab/BattUse/wiki) !

## Installation

Install the widget the same way as any other EdgeTx tools cript:  
Extract the contents of the downloaded `.zip` file into the `/SCRIPTS/TOOLS/BattUseView` folder on your radio.

There are a few more steps to take, read the [Wiki page](https://github.com/Be-Gab/BattUse/wiki) !
